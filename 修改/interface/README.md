# 指令、描述符与完整输出

保留 `custom3=0x7b, funct7=0x40, funct3=110, rs2=x0`，rs1 为 4 字节对齐描述符，rd 返回状态。32 位单笔 ICB；NICE 包装端口保持 r8，`MEM_BASE/MEM_BYTES` 必须由平台显式设置为合法 512 KiB 共享窗口，默认零会拒绝任务。不能直接指向 ITCM/DTCM 替代共享 SRAM。

| 描述符字 | 字段 | 当前定义 |
|---|---|---|
| 0 | magic | `0x3154574b` |
| 1 | format | **`0x00010005`**，旧 `0x10004` 明确报错 `0x12` |
| 2 | layer | 0..11；标记层号，W/b 必须由驱动正确选取 |
| 3 | X | 预留 16 KiB，四路原输入码流 |
| 4 | W | 预留 64 KiB，16 列组的原权重码流 |
| 5 | bias | 256 个 signed32，共 1 KiB |
| 6 | Y | 仍预留 64 KiB；仅前 50,688 字节为完整输出矩阵 |
| 7 | scales | sx[3:0]=1..5、sw[7:4]=3..5、sy[11:8]=0..5，高位为零；冻结 profile 不变 |

描述符/X/W/b/Y 对齐且不能重叠，整个保留区都必须位于合法窗口。成功状态 0；1 范围/输入码流，2 读错，3 写错，4 层号，0x10 指令，0x11 描述符地址，0x12 格式，0x13 描述符读取。真实 E203 对 `nice_rsp_err` 的异常处理由平台驱动负责，不保证错误时 C 函数可正常返回。

## 数值与布局

X signed16/F11，W signed16/F16，bias signed32/F27，累加 signed40/F27。先使用 r8 的最近偶数舍入转为 Y signed16/F11 并饱和；再按冻结 sy 舍入到 2^sy 的整数倍，半步向正无穷并饱和。这是原数值设计的一部分，本次保留。**把舍入值恢复到完整 16 位后写入**，sy 对应低位零也实际存储，不缩短任何元素，不作差分或变长编码。

默认 `PACK_LOW_FIRST=1`：字 `i` 的低 16 位为元素 `2i`，高 16 位为元素 `2i+1`；元素索引 `row*256+col`。`PACK_LOW_FIRST=0` 只交换两个半字。读取有符号整数后除以 2048 即浮点数；不需要 Rice key、预测器或 sy 解压。

`kwt_make_streams_descriptor` 现在生成 0x10005。`kwt_decode_streams_y` 为兼容调用名称保留，但实现仅是固定两半字拆分；`sy` 只校验范围。`KWT43_Y_WORDS=16384` 是保守预留长度，`KWT43_Y_DATA_WORDS=12672` 是实际读取长度。输入 X/W 编码 API 不变。

其余 v4/v4.1/v4.2 头文件被当前头文件作为类型和输入编码辅助依赖。其历史描述符构造/输出解码接口不属于当前 ABI，不能直接调用。接入时只使用 `kwt_v43_streams.h` 暴露的当前入口。

原 P6 main.c 使用同名构造函数，重编译时会自动取得新格式号；**不能继续使用原 firmware.hex**。本目录未提供未经整机测试的新固件镜像。P6 装载旁路整改见 reports/03。
