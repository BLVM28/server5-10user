## 工具文件

| 文件 | 作用 |
|---|---|
| prepare_cleanup.py | 只读枚举、哈希、打包、重新验证 ZIP，生成明确删除计划 |
| apply_cleanup.ps1 | 删除前核对全部 SHA、工作区边界及 reparse point，再用原生 PowerShell 删除/移动 |
| write_folder_readmes.py | 为本次目录布局生成说明；只用于这次整理，不是持续同步服务 |
| verify_workspace.py | 审计受保护文件、归档、链接及自有目录说明覆盖 |
| environment_after.log | 缓存删除后 NumPy/TF/Addons 导入检查 |

不要无条件重跑整理脚本：prepare 对既有归档有防覆盖断言，apply 期待整理前散文件，README 生成器也不是幂等编辑器。日常只需阅读结果、跑正常模型/RTL 验证入口。
