# 加速器独立验证

`tb_kwt_stream_dot` 校验有符号点积的 64 组测试。其余工作负载由 `tb_kwt_streams` 驱动，使用确定的矩阵 golden 与非法描述符、坏位流、错误应答和复位等检查。四种总线模式分别覆盖基本应答、等待和反压、同拍应答及公共 SRAM 控制器。每种模式核对 29 个功能用例和 25 个保护用例。

服务器在 v4.5 根目录执行 `make run`。向量目录和模型在 [paths.tcl](../soc/flow/paths.tcl) 配置。真实 E203 的固件启动及端到端矩阵核对位于 [整机测试](../soc/README.md)。
