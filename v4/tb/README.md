# 功能验证与计时

| 测试 | 判据 |
|---|---|
| tb_kwt_arithmetic、tb_v3_carries、tb_kwt_mul_pipeline | 260/260 独立算术、7/7 分段进位与取消、524288/524288 遍历乘积。最后一个含空拍/复位共 527566 个有效乘积检查 |
| tb_kwt_icb | 4/4，覆盖背压、零等待、延迟响应和错误。系统 BFM 另检查命令在堵塞时稳定 |
| tb_kwt_system | 29/29，原格式的全部 40 位中间值、25,344 个 Y、饱和计数、总线写入与输出护栏。输入和参数从冷状态重新装载 |
| tb_kwt_compact | 使用完全相同的随机存储器和系统测试，只选择新 format。独立读取总线物理内存和标签，解码逐个比对原 int16 金值，并检查写数、每个未写槽、最后标签位、末标签写错和扩大后的内存范围 |
| tb_kwt_negative | 58/58，非法区间、重叠、参数首末读错、写错和恢复 |
| tb_kwt_overlap | 5/5 既有主工况，另覆盖下一页 DMA 中复位/读错、同拍 W 读写或 Y 读写必须在异页、计算先完成而等待慢 DMA |
| tb_kwt_codec | 4096/4096 编码边界与随机数，包括 ±32768/32767 极端相减、各编码阈值、跨字 lane 与原格式 |
| tb_kwt_export | 本地额外使用同一系统 TB，捕获 12 张实际总线输出，供 C 和 Python 消费端解码和逐字核验 |
| tb_kwt_fast_return | 一张数学结果可直接构造且覆盖四种编码的冷矩阵。每笔 ICB 命令接受时立即返回，逐笔核对正确的物理槽、标签和次数，专门检查提前读取下一行的边界 |
| [tb_core_all_gate](../server_eda/tb_core_all_gate.sv) | 带实际 SDF 的完整核网表，由外部 NICE/ICB 引脚驱动并解码输出。make gate_sample 测紧凑模式的第 0 层，make gate 可扩展为原格式 12 层。tb.zip 内按服务器路径保留该文件 |

系统测试打印 NICE_TIME。计时从 NICE 指令握手沿至完成响应首次有效，包含描述符、所有冷装载与读/写应答，不含测试台故意延长的响应背压和任务间复位。每次执行含 12 次首次任务、两次恢复重测，吞吐仅取前 12 次。测试仍使用原随机等待分布与相同种子。正式 E203 固件调度需另测。[证据](../results/README.md)
