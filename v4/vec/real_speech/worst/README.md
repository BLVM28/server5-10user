# worst · 逐层较大误差

层 0 到 11 的源样本 ID 为 `[0, 0, 0, 0, 0, 0, 0, 287, 15, 0, 0, 88]`。每个层号都有 X、W、b 三个输入文件和 Y、acc 两个独立期望文件。matrix_sat.hex 给出十二层各自的饱和计数。各层按数值误差单独选择，所以这组向量可以由多段语音组合而成。

原格式每层写回 12672 个 32 位字。紧凑格式实际写数随数据而变，两者都必须还原同样的 99×256 个 int16。用系统 TB 对照全部写回字、40 位累加值和事务数。样本 ID 是软件验证集索引。[其它类别及命令](../README.md)
