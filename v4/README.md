# v4 · E203 三行八列 Dense1

同一批 12 层冷启动任务，v4 的紧凑格式用 **1,568,392 个 NICE 周期**。在赛题 150 MHz 折算为 **1,147.67 tasks/s**。相同输入的原始 int16 格式为 **895.38 tasks/s**。任务从指令握手计至首次完成响应，含描述符、输入与参数装载、总线等待和所有写应答。[频率与面积实测](RESULTS.md) · [服务器验收](SERVER_RESULTS.md)

12 个类别各取一个语音样本，跑完共 144 层的总吞吐为 **1,051.22 tasks/s**，各类为 **1,027.67–1,186.51**。难压缩合成样本为 **949.56**。完整新增核心前端综合面积为 **0.319784 mm²**，较 v3.1 增加 106.19%。[按类别的数据与面积](RESULTS.md)

每个 task 产生一张 99×256 的 Dense1 输出矩阵。一次读入 99×64 个 X、64×256 个 W 与 256 个 b，返回完整的定点输出。三个不同行共享八个列权重，实际有 24 路乘加器。每个结果仍经过 signed16×signed16、40 位累加、一次最近偶数舍入和饱和。预测词标签由模型后续部分生成。

## 与 v3.1 的变化

| 部分 | v3.1 | v4 |
|---|---|---|
| 数学执行 | 一行八列，8 个 MAC | 三行八列，24 个 MAC。三个独立行共用一组 W，99 行正好分成 33 组三行 |
| 访存重叠 | 同一组权重 SRAM 划两页，偷一拍计算端口装下一组 | DMA 和计算各有状态机。计算 g 时装 g+1 的权重并写回 g−1 的结果，双页由不同单口宏实现 |
| ICB | 内部请求和返回各经过寄存状态 | 保持 32 位及一笔在途。立即握手时直接传递，遇到阻塞用寄存器保持命令/应答 |
| Y 格式 | 固定 12,672 个 32 位输出字 | 原格式仍可选。扩展格式在 RTL 对已量化结果做无损编码，写出的 32 位字数随数据变化 |
| 成本 | 15 个宏，16 KiB | 41 个宏，20.75 KiB。标准单元和宏面积一起统计 |
