# 五个分类包

[rtl.zip](rtl.zip) 包含 14 个硬件模块、rtl.f 和模块说明。[tb.zip](tb.zip) 包含功能测试、自检、模型和各测试判据。[makefile.zip](makefile.zip) 包含根目录与 server_eda 的 Makefile 以及服务器操作手册。[flow.zip](flow.zip) 装有 EDA 脚本、驱动/解码器、软件模型与工程报告。[vectors.zip](vectors.zip) 包含固定输入、原始未经压缩的准确度金值、各类样本说明和逐文件清单。

[manifest.json](manifest.json) 记录每个包及全部成员 SHA。恢复时保留目录关系。服务器工艺与工具依赖见[手册](../SERVER_GUIDE.md)。
