# 分类归档 · 直接解压

[rtl.zip](rtl.zip) 含 10 个 RTL 与 rtl.f。[tb.zip](tb.zip) 含七套测试及 SRAM 行为模型。[makefile.zip](makefile.zip) 含根和 server_eda 转发 Makefile。[flow.zip](flow.zip) 含 Python、Tcl、E203 包装、版本说明和公开结果。[vectors.zip](vectors.zip) 含冻结测试向量及其格式说明。

解压时保留路径层次。服务器需要已有的个人 shared 工艺选择和同仓 v2 工具配置。商用库、网表、DDC 与 SDF 保留在服务器。[manifest.json](manifest.json) 记录各包及成员 SHA-256。从版本根执行 make package 可重建并校验。
