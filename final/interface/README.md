# E203 接口、数值格式与码流

`e203_subsys_nice_core.v` 来自实测 P6 的对接参考，平台需提供 `e203_defines.v`、打开 `E203_HAS_NICE`，选择 32 位 `E203_XLEN` 和 `E203_ADDR_SIZE`，按已验证的共享内存配置设置 `KWT_MEM_BASE/KWT_MEM_BYTES`。实际编译清单选择一个 NICE wrapper。`kwt_v43_streams.h` 为 C 码流入口，其余头文件提供冻结 profile 和共用类型。P6 实测字序为 `KWT_PACK_LOW_FIRST=1`。

NICE 使用 custom3 opcode `0x7b`、funct7 `0x40`、funct3 `110`、`rs2=x0`。`rs1` 是四字节对齐的描述符指针，`rd` 返回状态。ICB 单笔在途，`cmd_size=2` 表示 4 字节。NICE 响应在最后一笔输出写应答后产生，并保持到 `nice_rsp_ready`。集成时使 CPU/NICE/互连的响应域共同复位，以取消未完成事务。

| 描述符 32 位字 | 内容 |
|---:|---|
| 0 | magic `0x3154574b` |
| 1 | format `0x00010004` |
| 2 | layer `0–11` |
| 3 | X 首地址，预留 16 KiB |
| 4 | W 首地址，预留 64 KiB |
| 5 | bias 首地址，256×32 位，共 1 KiB |
| 6 | Y 首地址，预留 64 KiB |
| 7 | `sx[3:0]`、`sw[7:4]`、`sy[11:8]`，高 20 位为零 |

描述符和四个数据区在合法共享窗口内，四字节对齐且互不重叠。状态 `0` 成功，`1` 范围、重叠或码流错误，`2` 输入传输失败，`3` 输出传输失败，`4` 层号错误。`0x10/0x11/0x12/0x13` 分别是指令、描述符地址、描述符格式、描述符读取错误。软件仅在成功返回后消费 Y。

| 张量 | 尺寸 | 定点格式 |
|---|---|---|
| X | 99×64 | signed 16/F11 |
| W | 64×256 | signed 16/F16 |
| bias | 256 | signed 32/F27 |
| 累加 | 99×256 | signed 40/F27 |
| Y | 99×256 | signed 16/F11 |

F 为小数位数。浮点转换与 MAC 最后移位使用最近偶数舍入，超出表示范围时饱和。码流缩放按 `sx/sw/sy` 舍入到最近的步长倍数，半步向正方向，随后饱和到有效位宽。冻结 profile 给出 `sx=1–5`、`sw=3–5`、`sy=0–5` 和 Y Rice 参数。

- **X** 使用 4 个 1,024 字槽。子流 s 处理行 `s,s+4,…`。字 0 是 payload 字数，字 1–8 存 64 个 4 位 Rice 参数。按列、子流内行顺序，首值相对零，其后为差分。补齐行 99 参与输入长度检查。
- **W** 每 16 列一组，共 16 组，每组 4 个 256 字槽。组 g 子流 s 的列为 `16g+s+4j`，`j=0–3`。字 0 是 payload 字数，字 1 的低/高半字分别存 W/Y 的四个 Rice 参数。绝对值按 k、j 排列。
- **bias** 256 个 signed 32 位字，按列。
- **Y** 与 W 同样的组和槽位。字 0 低半字为四个 Y Rice 参数，高半字为零。按有效行、组内四列解码 396 个符号。每列首值相对零，后续为差分，剩余槽位保留原内容。

规范字低半字在前，位流从 LSB 开始。zigzag 后商小于 4 时编码为 unary `1…10`、k 位余数，否则四个 `1` 后跟 `16-shift` 位绝对量化数。最后字未使用位为零。使用实际平台字序设置保持 RTL 与 C 一致。
