# E203 软件和内存格式

`e203_subsys_nice_core.v` 包装 32 位 NICE 请求/应答及 ICB 信号。集成时由平台在编译阶段提供经确认的 `KWT_MEM_BASE`、`KWT_MEM_BYTES`。默认窗口长度为零；验证用窗口是测试台分配的 0x10000000、512 KiB。复位须与未完成 ICB 响应的总线域一致。

[Precision42 接口](kwt_v42_precision.h) 与 [冻结参数](kwt_v42_profile.h) 供软件调用。描述符八个 32 位字依次为 magic 0x3154574b、格式 0x00010003、层号 0…11、X/W/b/Y 的字节地址、数值移位。最后一个字低三个半字节依次是 sx、sw、sy，分别允许 0…5；其余位清零。描述符和数据区须字对齐、互不重叠，描述符与 b 总是原生字序。

| 区域 | 预留 | 物理布局 |
|---|---:|---|
| X | 4,096 字 | 第一个字为有效载荷字数，后 8 字为 64 个四位 k；按列对、行、两通道顺序写入位流。 |
| W | 32×512 字 | 每组依次为载荷字数、8 个 W 的 k、8 个 Y 的 k、按 k 维展开的 64×8 系数流。 |
| b | 256 字 | 256 个有符号 F27 偏置。 |
| Y | 32×512 字 | 每组第一字为 Y 的 k，随后依行输出 99×8 个符号，未使用的字保持原值。 |

典型调用顺序是为共享 RAM 分配各区，按层用 `kwt_v42_profiles[layer]` 编码 X/W，写 b，以 `kwt_make_precision_descriptor` 建描述符，发出 `kwt_run`，成功后用 `kwt_decode_precision_y` 得到 99×256 个 F11 数值。[RV32 调用示例](precision_rv32_probe.c) 已交叉编译；宿主 C 编码对照数据覆盖标准和半字交换两种布局。每层 W 可预先转为本格式，但每个计时任务仍须从共享 RAM 装入核心。每任务 CPU 编码、调度和解码的实际成本取决于平台计时窗口。
