# 测试平台

- `tb_kwt_precision` 以 NICE 请求为起点，真实随机等待的 32 位总线驱动所有数据。每层比较 25,344 个原始 40 位和、物理写回的所有字、独立解码的 25,344 个矩阵元素、读写笔数及饱和计数。保留原来的 29 个系统场景，新加 9 个格式/范围/总线错误场景。
- `tb_kwt_rice_codec` 覆盖 k=0…15、六种移位、全范围正负残差、四个一的转义、FIFO 反压、跨字及尾字。1,542 个符号中，520 个跨 32 位字边界。
- `tb_kwt_precision_immediate` 在命令接受边沿同时返回响应，检查 12 层实际地址和数据。`tb_kwt_modes` 连续切换四种格式并注入错误，无需复位即可继续。
- `tb_kwt_system/compact/block8` 是兼容性矩阵测试。算术、乘法、ICB、页重叠、复位/异常和 Block8 编解码另有独立用例。测试台的 SRAM 模型用于本地 XSim，服务器 VCS 使用只读公共宏模型。
- `tb_kwt_stream_dot` 对新流水点积逐个核对 64 组极值、正负抵消、偏置、半步舍入、饱和及中途 clear。Rice 单元另外验证脏尾字、残缺前缀和恰好字对齐。
- 网表仿真顶层位于 [server_eda](../server_eda/README.md)，测试时独立解码实际外部 RAM，并检查未写区域的哨兵值。
