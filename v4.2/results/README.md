# 公开测量数据

accuracy.json、accuracy_cases.json、accuracy_provenance.json、accuracy_audit.json 给出逐层、逐条、样本及来源校验。training_samples.json 单独列出标定输入。functional.json 是本地 XSim 三行/四行对照，workloads.json 是服务器 VCS 的四种格式逐组原始周期与读写数。ppa.json、gate.json、extra.json 分别记录全核双角 STA、整矩阵 SDF 和定向检查。driver.json、rv32.json 对应 C 比对及指令反汇编。[总报告](../RESULTS.md)
