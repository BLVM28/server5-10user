# E203 接口与三种数据布局

对外仍为 NICE custom3（funct7 0x40、funct3 6、rs1 指向八字描述符）和 32 位单笔 ICB。描述符依次为 magic、format、layer、X/W/b/Y 地址、保留 0。每个数据区按字对齐且互不重叠。默认 MEM_BYTES=0 会拒绝任务。测试基址 0x10000000 只属于 TB。公开平台的真实共享 SRAM 地址和固件调度仍应在整机核实。[包装](e203_subsys_nice_core.v) · [原始驱动](kwt_driver.h)

| format | X / W / b / Y 字节 | 软件入口 |
|---|---|---|
| 0x00010000 | 12,672 / 32,768 / 1,024 / 50,688 | 连续 int16 Y，沿用 v4 原始数值 |
| 0x00010001 | 12,672 / 32,768 / 1,024 / 51,584 | 最终定点 Y 无损差分，[v4 解码器](kwt_v4_output.h) |
| 0x00010002 | 6,732 / 16,512 / 1,024 / 27,008 | 分块八位 X/W/Y，[v4.1 编码、描述符与解码器](kwt_v41_block8.h) |

传输前 X 为 signed16/F11，W 为 signed16/F16，b 为 signed32/F27，解码后的 Y 仍用 signed16/F11 解释。例如返回整数 2048 代表 1.0。

全部偏移以 32 位字为单位。X 第 r 行起点 17r，第一个字低 4 位为指数，余下 16 字每字四项。W 第 g 个八列组起点 129g，第一个字包含八个列指数，后续 128 字按 k 顺序每次两字存八列。偏置按本机 32 位字原样读取。Y 的前 6,336 个字按行主序，每字四个尾数。第 r 行第 g 组的指数在 `6336+13*g+r/8` 字的第 `4*(r%8)` 位起。末指数字未使用的高位清零。若配置 PACK_LOW_FIRST=0，以上 X/W/Y 的整字都交换两个半字，bias 和描述符保持 RV32 原生次序。

平台加载器可用 `kwt_encode_block8_x`、`kwt_encode_block8_w` 从 v4 固定点转换。分配四个完整缓冲区，构造 `kwt_make_block8_descriptor` 并执行 `kwt_run`。只有返回 KWT_OK 后才能调用 `kwt_decode_block8(src,6752,dst,25344,low_first)`。src/dst 分开，返回 0 表示成功。区间/非法流头返回 1，输入读错返回 2，写错返回 3。出错时整张 Y 无效。实际 E203 平台还需遵循缓存一致性、异常及地址约定。[驱动编译探针](block8_driver_probe.c) · [主机端测试](block8_probe.c)
