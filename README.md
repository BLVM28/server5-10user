#  KWT 前馈线性加速器工作区

**本工程给 E203 增加一个计算 `Y=XW+b` 的专用硬件。它处理神经网络中间矩阵，不直接接收麦克风，也不直接输出 yes/no。** 
本科赛题只要求第一层前馈线性计算、数值处理，以及 SoC 集成与综合。依据：赛题印刷 p5、p7–8。

## 当前到底完成到哪里

| 项目 | 当前结论 | 不能扩大成什么结论 |
|---|---|---|
| 点积、量化、整矩阵控制 | 原有回归通过；12 层 W/b 可切换；RTL 与整数金模比对 | 不等于全部真实语音样本精度已通过 |
| 语音相关输入 | 已跑静音与合成音调 smoke；指定权重已导出 | 不是正式 Speech Commands 验证集或官方 600 样本验收 |
| E203 接口 | 已对实际公共版端口、宏与包装做核对/测试；有 RV32 指令头 | 没有完成真实 CPU 启动固件、共享 RAM、NICE 指令到写回的 SoC 联调 |
| 赛用 SMIC40 时序 | fix1 整核/dot64 双角无报告违例；两版 layer-0 整核 SDF 通过 | 余量很小、仍有未测检查；不是完整 SoC/PPA 已验收 |
| 私有 VM | 完整加速器 RTL 回归、dot64 双角 STA/SDF 通过 | VM 缺赛用 SRAM timing 库，不代表 VM 完整核时序通过 |
| 赛题任务 3 | 接入材料、独立核综合和测试已准备 | CPU 整机、正式内存与统一功耗/能耗统计尚未完成 |

赛题印刷 p3 明确**不包括布局布线、物理验证和流片**。因此缺 CTS/SPEF/后端签核属于报告适用范围限制，不应当成新增本科必交任务。仍必须完成 150 MHz 合理约束的逻辑综合时序、规定面积、功耗活动、SoC 功能及复现报告。

## 服务器日常操作（2026-11-02）

本地与服务器的 v1/v2 源码、TB、Makefile 和流程目录一致；生成产物和工艺库不在公开仓库复制。先读 [v2 手动操作](v2/SERVER_GUIDE.md) 和 [本轮结果](v2/SERVER_RESULTS.md)。

```sh
cd /storage2/2026contest/server5/s5_10usr/v2
make check
make waves
make verdi
```

`make check` = 环境 + 基础功能 + SS/FF STA + 指标汇总。`make clean/compile/run/timing/report/package` 可分别执行。保守联调建议 125MHz；150MHz 静态检查通过但 setup 余量极小。长门级测试属于可选项，正式 E203 整机接入仍需共享 SRAM 与固件材料。
