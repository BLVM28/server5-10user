#  KWT 前馈线性加速器工作区

**本工程给 E203 增加一个计算 `Y=XW+b` 的专用硬件。它处理神经网络中间矩阵，不直接接收麦克风，也不直接输出 yes/no。** 
本科赛题只要求第一层前馈线性计算、数值处理，以及 SoC 集成与综合。依据：赛题印刷 p5、p7–8。

## 服务器日常操作（2026-11-02）

本地与服务器的 v1/v2 源码、TB、Makefile 和流程目录一致；生成产物和工艺库不在公开仓库复制。先读 [v2 手动操作](v2/SERVER_GUIDE.md) 和 [本轮结果](v2/SERVER_RESULTS.md)。

```sh
cd /storage2/2026contest/server5/s5_10usr/v2
make check
make waves
make verdi
```

`make check` = 环境 + 基础功能 + SS/FF STA + 指标汇总。`make clean/compile/run/timing/report/package` 可分别执行。保守联调建议 125MHz；150MHz 静态检查通过但 setup 余量极小。长门级测试属于可选项，正式 E203 整机接入仍需共享 SRAM 与固件材料。

## v3 正式工程与交付包

服务器个人工作目录的 `v3/` 是可手动操作的版本根。执行 `make check` 会跑七组功能测试、默认 200 MHz 的完整 NICE 核双角 STA，并打印计数和余量。要按赛题时钟比较，执行 `make timing PERIOD=6.666667`。五个公开分类包和校验清单可从 [v3/packages](v3/packages/README.md) 取得。工艺库、映射网表与完整 EDA 构建记录留在服务器。

版本选择取决于评估口径。相同 150 MHz 下，固定 12 个任务的 v2/v3 吞吐折算为 441.0/432.9 task/s。按 v3 实际通过的 200 MHz 折算为 577.3 task/s，SS setup 余量为 0.194 ps。面积与覆盖明细见 [v3 实测](v3/RESULTS.md)。
