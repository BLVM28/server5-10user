# 正式 RTL：15 个文件

`../rtl.f` 是唯一正式清单。顶层 `kwt_nice_core` 的 NICE/ICB 端口与公共 32 位 E203 对接；时钟为同一 `nice_clk`，低有效异步复位。宏模型/黑盒不能同时作为功能模型使用。

| 文件 | 负责什么，和谁连接 |
|---|---|
| kwt_nice_core.sv | 接受 custom3 长指令，读 8 字描述符，检查 magic/格式/层号/地址，启动 core，保持响应直到 E203 接收；等待期间阻塞冲突的访存 |
| kwt43_icb_master.sv | 32 位单在途 ICB，维持反压时命令稳定、读写响应归属、零延迟响应与应答/下一命令交接 |
| kwt43_core.sv | X/W/Y 区域和互斥检查，16 列组、双页调度，绑定 W/bias/Y 参数页面，协调 reader/compute/writer 与错误排空 |
| kwt43_reader.sv | 四子流头部、轮转读字、返回字信用，四解码器同步取符号，恢复 X 行差分或 W 绝对值，写本地银行并装 bias |
| kwt43_unpack.sv | 有界 Rice FIFO、最多四个 unary 1 后绝对数 escape；检查末尾填零/字数，短尾不读取无效下一字 |
| kwt43_compute.sv | 8 行×16 列实例化与 k/tile 发射，X/W 同步返回对齐，逐行提交 99 行有效结果 |
| kwt43_dot.sv | 每 PE 的 64 项点积，14/13/13 位延迟进位累加，独立结束归并；输入低位常零优化和 40 位有符号保护 |
| kwt_mul16_pipe.sv | 分解的有符号 16×16 流水乘法，valid/last 同步，遇到 clear 清空未完成事务 |
| kwt_quantize.sv | F27→F11 最近偶数舍入、正负饱和和饱和标志 |
| kwt43_xram.sv | 8 个 1024×16 单口 X 条带；四路写装载，计算读时送八个行值 |
| kwt43_wram.sv | 两页各 16 列的 128×16 W 银行；加载页写、计算页读，按 k 同拍送 16 个权重 |
| kwt43_yram.sv | 两页各 16 列的 128×16 Y 银行；当前结果写、前组编码读 |
| kwt_sp_ram.sv | 统一单口宏时序封装；综合链接真实 RAMSP 宏，普通本地仿真用同步数组模型 |
| kwt43_writer.sv | 每组四个子流分别维护四列预测值和 k，四路编码，仲裁 32 位输出并等待每笔写应答 |
| kwt_rice_pack.sv | 一个符号的 bounded-Rice 打包和末字零填充；四个实例共同反压，避免少数通道偷跑 |

`W_BANK_AW=7` 是为了旧 wrapper 保留的兼容参数；v4.3 实际固定使用 128 字银行，不能靠改这个参数选择另一架构。默认 `MEM_BYTES=0` 会拒绝任务，必须按正式地址设置共享窗口。仿真的 0x10000000/512 KiB 是测试配置。

物理位容量为 32 KiB、72 个单口宏，输出仍有 25,344 个 int16。W/Y 的页号、组号和 Rice 参数必须一起维护。对接前先读 [接口说明](../integration/README.md)。
